# Included entry fonts

These fonts are bundled for offline use. Each folder includes its SIL Open Font
License; keep the license with the font when distributing Ukijiten.

| Family | Style | Source |
| --- | --- | --- |
| Zen Maru Gothic | Rounded | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/zenmarugothic) |
| Yomogi | Handwriting | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/yomogi) |
| Hachi Maru Pop | Playful handwriting | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/hachimarupop) |

Other choices use installed system fonts. The selector groups Japanese,
simplified Chinese, traditional Chinese and other installed families. Font
selection changes entries in both dictionary views, leaving interface text alone.
