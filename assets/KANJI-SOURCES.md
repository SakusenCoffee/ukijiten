# Kanji reference sets

`kanji_catalog.json` contains factual character memberships, transcribed from the installed Kanji Grid Kuuube data (`official_kanji.json`, `grade.json`, `jlpt_level.json`). No add-on program code is included.

- Jōyō: 2,136 unique characters in the 2010 Cabinet list, published by Japan’s Agency for Cultural Affairs: https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kijun/naikaku/kanji/
- School grades and JLPT memberships retain their source URLs in the JSON. JLPT groupings are study reference lists, not an official examination syllabus.
- Jōyō character forms include 剝, 頰, 塡 and 𠮟. Their common variants 剥, 頬, 填 and 叱 count toward these cells.
